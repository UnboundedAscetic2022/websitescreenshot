# Website Screenshot

Webサイト、HTML、モバイルページを **JPG、PNG、WebP、PDF** として保存できる多言語スクリーンショットツールです。

## 主な用途

- Webサイトのスクリーンショット
- HTML を画像または PDF に変換
- iPhone サイズでのページ確認
- Android サイズでのページ確認
- フルページスクリーンショット
- Webページを PDF として保存

## 主なページ

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## 向いているユーザー

- レスポンシブ確認を行うデザイナー
- UI や長いページを確認する QA チーム
- LP やキャンペーンページを保存したいマーケター
- HTML テンプレートを画像化したい開発者

## ローカル起動

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

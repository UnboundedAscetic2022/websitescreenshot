# Website Screenshot

Alat berbilang bahasa untuk menangkap laman web, HTML dan halaman mudah alih sebagai **JPG, PNG, WebP atau PDF**.

## Kegunaan utama

- screenshot laman web
- HTML ke imej atau PDF
- pratonton dalam saiz iPhone
- pratonton dalam saiz Android
- screenshot halaman penuh
- simpan laman web sebagai PDF

## Halaman utama

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## Sesuai untuk

- pereka yang menyemak layout responsif
- pasukan QA yang memeriksa halaman panjang dan UI
- pasukan pemasaran yang menyimpan landing page
- pembangun yang mengeksport template HTML

## Jalankan secara lokal

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

把网站、HTML 和移动端页面导出为 **JPG、PNG、WebP 或 PDF**。

**Website Screenshot** 是一套围绕真实用户需求打造的多语言截图与导出产品。无论你想做 **网站截图**、**网页截图**、**网页快照**、**URL 转图片**、**HTML 转图片**、**HTML 转 PDF**、**iPhone 截图预览**、**Android 截图预览**，还是 **整页截图**、**长网页截图**、**网页转 PDF**，这套项目都能覆盖。

## 为什么值得用

很多工具只能解决一个点状需求：

- 只能截网站，不能处理 HTML
- 只能导出图片，不能导出 PDF
- 只能看桌面端，不能看手机尺寸
- 只能截首屏，不能做整页截图

Website Screenshot 把这些相互关联的需求统一到一个产品里：

- 网站截图
- 网页截图
- 网页快照
- URL 转图片
- HTML 转图片
- HTML 转 PDF
- 网页转 PDF
- iPhone 截图
- Android 截图
- 整页截图
- 长网页截图
- 移动端整页截图

## 核心能力

- 输入网站 URL，导出 JPG、PNG、WebP 或 PDF
- 把 HTML 和 CSS 渲染成图片或 PDF
- 保存整页，而不是只保存首屏
- 按常见 iPhone 尺寸预览网页
- 按主流 Android 机型尺寸预览网页
- 保存长落地页、产品页、帮助页和博客页，用于 QA、评审和归档

## 输出格式

- JPG：适合轻量分享
- PNG：适合 UI 细节和视觉 QA
- WebP：适合更现代的图片输出
- PDF：适合审批、归档、打印和文档流转

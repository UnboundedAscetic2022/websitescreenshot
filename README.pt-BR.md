# Website Screenshot

Uma ferramenta multilíngue para capturar sites, HTML e páginas mobile em **JPG, PNG, WebP ou PDF**.

## Principais usos

- screenshot de site
- HTML para imagem ou PDF
- pré-visualização em tamanhos de iPhone
- pré-visualização em tamanhos de Android
- screenshot de página inteira
- salvar página web em PDF

## Páginas principais

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## Indicado para

- designers revisando layouts responsivos
- times de QA verificando páginas longas e UI
- marketing salvando landing pages
- desenvolvedores exportando templates HTML

## Executar localmente

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

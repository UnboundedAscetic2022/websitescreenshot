Capture websites, HTML, and mobile pages as **JPG, PNG, WebP, or PDF**.

**Website Screenshot** is a multilingual screenshot platform built for people who need to turn live web pages, HTML snippets, long-form landing pages, and mobile layouts into shareable visual assets. If you are looking for a **website screenshot tool**, **webpage screenshot generator**, **website snap tool**, **HTML to image converter**, **HTML to PDF workflow**, **iPhone screenshot preview**, **Android screenshot preview**, or **full page screenshot tool**, this project is designed around those real search intents and use cases.

## Why Website Screenshot?

Most screenshot tools solve only one narrow task. One tool captures a URL but cannot handle HTML. Another exports images but not PDF. Another works for desktop but not for mobile review. Another only saves the visible viewport instead of the full page.

Website Screenshot combines those workflows in one product:

- website screenshot
- webpage screenshot
- website snap
- page capture
- URL to image
- HTML to image
- HTML to PDF
- website to PDF
- iPhone screenshot
- Android screenshot
- full page screenshot
- long webpage screenshot
- mobile full page screenshot

That makes it useful for direct product usage, SEO landing page coverage, and GitHub discovery at the same time.

## What You Can Do

- Capture any website URL as JPG, PNG, WebP, or PDF
- Save a full page screenshot instead of only the first visible screen
- Render HTML and CSS into image output
- Export HTML and CSS as PDF
- Preview a page in popular iPhone screen sizes
- Preview a page in popular Android phone sizes
- Save long landing pages, product pages, help docs, and editorial pages for QA, review, and archive workflows

## Key Benefits

- **Multiple export formats**: JPG, PNG, WebP, and PDF in one flow
- **Full-page support**: useful for long pages and scroll-heavy layouts
- **Mobile device presets**: compare real iPhone and Android screen sizes
- **HTML workflows**: render pasted HTML or uploaded files visually
- **Multilingual structure**: UI and landing pages support multiple languages
- **API-ready architecture**: suitable for automation and product integration

Yes. Full-page capture is one of the main strengths of the project.

### Can I compare mobile layouts across multiple devices?

Yes. The device library covers popular iPhone and Android models for responsive review.

### Is PDF supported?

Yes. Both website to PDF and HTML to PDF workflows are supported.

Yes. The project is built around landing pages that match user search intent while still delivering a real tool experience.

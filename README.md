## What This Project Is

**Website Screenshot** is a multilingual web app for:

- website screenshot
- webpage screenshot
- HTML to image
- HTML to PDF
- iPhone screenshot preview
- Android screenshot preview
- full page screenshot
- website to PDF

It supports JPG, PNG, WebP, and PDF export, plus desktop, iPhone, Android, and full-page workflows.

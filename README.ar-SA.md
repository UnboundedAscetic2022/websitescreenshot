# Website Screenshot

أداة متعددة اللغات لالتقاط مواقع الويب وملفات HTML والصفحات المحمولة بصيغ **JPG وPNG وWebP وPDF**.

## الاستخدامات الرئيسية

- لقطة شاشة لموقع ويب
- تحويل HTML إلى صورة أو PDF
- معاينة الصفحة بأحجام iPhone
- معاينة الصفحة بأحجام Android
- لقطة شاشة لصفحة كاملة
- حفظ صفحة ويب كملف PDF

## الصفحات الرئيسية

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## مناسب لـ

- المصممين الذين يراجعون التصميم المتجاوب
- فرق QA التي تختبر الصفحات الطويلة والواجهات
- فرق التسويق التي تحفظ صفحات الهبوط
- المطورين الذين يصدرون قوالب HTML

## التشغيل المحلي

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

# Website Screenshot

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja-JP.md) | [Deutsch](README.de-DE.md) | [한국어](README.ko-KR.md) | [Français](README.fr-FR.md) | [Português (Brasil)](README.pt-BR.md) | [العربية](README.ar-SA.md) | [Русский](README.ru-RU.md) | [Bahasa Melayu](README.ms-MY.md)

웹사이트, HTML, 모바일 페이지를 **JPG, PNG, WebP, PDF**로 저장할 수 있는 다국어 스크린샷 도구입니다.

## 핵심 가치

Website Screenshot은 여러 관련 니즈를 한 제품 안에 모았습니다.

- website screenshot
- webpage screenshot
- website snap
- HTML to image
- HTML to PDF
- iPhone screenshot
- Android screenshot
- full page screenshot

## 할 수 있는 일

- URL을 이미지나 PDF로 저장
- 첫 화면이 아니라 전체 페이지 캡처
- iPhone 크기 미리보기
- Android 크기 미리보기
- HTML과 CSS를 이미지로 렌더링
- HTML과 CSS를 PDF로 렌더링

## 주요 페이지

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## 이런 분에게 적합합니다

- 반응형 레이아웃을 확인하는 디자이너
- 긴 페이지와 UI를 검토하는 QA 팀
- 랜딩 페이지를 저장하려는 마케팅 팀
- HTML 템플릿을 다루는 개발자

## 로컬 실행

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

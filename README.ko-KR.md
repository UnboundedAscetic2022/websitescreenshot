# Website Screenshot

웹사이트, HTML, 모바일 페이지를 **JPG, PNG, WebP, PDF**로 저장할 수 있는 다국어 스크린샷 도구입니다.

## 주요 기능

- 웹사이트 스크린샷
- HTML을 이미지 또는 PDF로 변환
- iPhone 크기 미리보기
- Android 크기 미리보기
- 전체 페이지 스크린샷
- 웹페이지 PDF 저장

## 주요 페이지

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## 이런 분에게 적합합니다

- 반응형 레이아웃을 확인하는 디자이너
- 긴 페이지와 UI를 검토하는 QA 팀
- 랜딩 페이지를 저장하려는 마케팅 팀
- HTML 템플릿을 렌더링하는 개발자

## 로컬 실행

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```

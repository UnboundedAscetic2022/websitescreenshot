# Website Screenshot

Многоязычный инструмент для сохранения сайтов, HTML и мобильных страниц в **JPG, PNG, WebP и PDF**.

## Основные задачи

- скриншот сайта
- HTML в изображение или PDF
- предпросмотр в размерах iPhone
- предпросмотр в размерах Android
- скриншот всей страницы
- сохранение веб-страницы в PDF

## Основные страницы

- `website-screenshot`
- `html-screenshot`
- `iphone-screenshot`
- `android-screenshot`
- `full-page-screenshot`
- `website-to-pdf`
- `html-to-pdf`

## Для кого

- дизайнеры, проверяющие адаптивные макеты
- QA-команды, тестирующие длинные страницы и UI
- маркетологи, сохраняющие лендинги
- разработчики, экспортирующие HTML-шаблоны

## Локальный запуск

```bash
pnpm install
pnpm run build
PORT=3021 pnpm start
```
